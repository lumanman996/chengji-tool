    三步上手

    1. 导入：在“开始”页把登分表拖进来（没有登分表，可以在那里下载各年级的空白模板）。
    2. 确认：看一眼识别出的科目和满分，选平时还是中考，起个考试名称，点“开始计算”。应考人数、上次名次都可以不填。
    3. 查看和导出：在“结果”页看各项统计，在“导出”页导出 Excel 和 PDF。

    算过的考试都在“开始”页的“最近的考试”里，随时可以打开回看、再导出。想先看看效果，点“用示例数据试一试”。

    登分表怎么填

    • 要有一行表头，写着“班级”“姓名”和各科目的名称；上面有标题行没关系。
    • 班级写成 七1、八3、九6（年级用汉字，班号用数字）。一张表只放一个年级。
    • 哪一列有成绩，就统计哪一科。这次没考的科目，那一列空着就行。
    • 要加一门科目：在后面加一列，表头写科目名称，下面填分数，会一起统计。
    • 缺考、请假：那一格留空，或写“缺考”。这名学生不计入统计，会列出来。0 分是真实成绩，照常计入。
    • 不要合并单元格，分数只填数字。

    名词解释

    应考人数
    应该参加考试的在籍学生。不填就按实考人数算。
    实考人数
    各科成绩齐全、计入统计的学生。缺考、请假、成绩不全的不算。
    单科得分
    一个班（或一位教师所教的学生）某一科的综合表现，由优秀率、及格率、平均分按比例合成。教师成绩用的就是它。
    综合得分
    一个班各科单科得分之和，“各班统计”按它排名。
    班级结构分
    满分 100 的班级评比分，由平均成绩、全科合格率、全科优秀率、参考率等几项按比例合成，另有增值评价或加分。
    全科合格率
    每一科都达到合格线的学生，占实考人数的比例。有一科不合格就不算。全科优秀率同理。
    参考率
    实考人数 ÷ 应考人数。
    进线率
    本班总分达到升学线的人数 ÷ 实考人数。
    两率一分
    也叫“二率一分”：全科合格率、全科优秀率、平均成绩这三项结构分得分之和，增值评价按它排名。
    增值评价
    先按两率一分排名，第 1 名得满分，每低一名减一点；再和上次考试的两率一分名次比，进步加分、退步减分。最高不超过满分。
    升学线
    全级总分排在前 N%（默认 85%）那一名学生的总分。同分的都算在线上。只是参考线，每次可以改。
    临界生
    总分在升学线上下若干分（默认 15 分）以内的学生。线下的是冲线重点，线上的要稳住。
    薄弱学科
    这名学生得分率（成绩 ÷ 满分）最低的那一科。
    级名次 / 班名次
    按总分在全年级 / 本班的排名，同分同名次。

    怎么算的

    合格线、优秀线默认是满分的 60%、80%。平时考试：单科得分 = 优秀率×25% + 及格率×25% + 平均分（折算成百分制）×50%。中考核算：单科得分 = 平均分（原始分，不折算）×60% + 合格率×40%。

    班级结构分各项的占比、增值评价怎么加减，都列在“设置 → 算法”里，那里显示的就是现在实际使用的数字，也可以按自己学校的办法改。改了之后只影响以后新算的考试。

    导出的 Excel 里全部是公式，“参数设置”工作表里改满分、比例，其他表会自动重算。

    试用与激活

    第一次打开起可以免费试用 3 天。试用结束后仍然可以核算、查看结果，导出 Excel 和 PDF 需要激活。激活码按电脑发放：点左下角“输入激活码”，把显示的机器码发给管理员，收到激活码后粘贴进去即可，全程不需要联网。换电脑或重装系统后需要重新申请。

    常见问题

    有一科没被统计？

    看“确认设置”左边的提示。多半是那一列下面不是数字，或者表头写成了“总分”“名次”这类。

    有学生没计入？

    他有一科是空的或写了“缺考”。导入后会列出是谁、缺哪一科。

    提示“文件写不进去”？

    要导出的 Excel 正被 Excel 或 WPS 打开着，关掉它再导出。

    没有生成 PDF？

    电脑上需要有 Edge 或 Chrome 浏览器（Windows 10、11 自带 Edge）。Excel 不受影响。

    改了一个分数想重算？

    重新导入再算一遍。用同一个考试名称会覆盖原来的结果（会提醒）；想两份都留，换个名称。

    删错了考试？

    删除的考试在结果文件夹的“已删除”里，把那个文件夹拖回上一层就恢复了。

    换电脑？

    把数据文件夹整个拷过去就行；激活码要按新电脑的机器码重新申请。
